# Phase 6T: hidden-allocation and native public-range diagnostic

Phase 6T closes two specific evidence gaps identified by Phase 6S. Hidden
particles now resample card allocation between deck, prize, hand, and a
face-down Active instead of only permuting order inside fixed zones. The
public-only Phase 6I range head is also evaluated on histories reached through
the native search engine. The result rejects that neural head under this domain
shift and identifies the simpler causal revealed-card updater as the stronger
next baseline.

## Allocation particles

`sample_hidden_zone_completion` samples without replacement from each
candidate's 60-card multiset while preserving:

- every agent-visible card;
- every already revealed prize identity;
- public deck, prize, and hand counts;
- the Basic-Pokemon constraint for a face-down Active; and
- exact total card multiplicities after explicit public-evidence adjustment.

The checked evaluation uses two independently started native roots, six deck
candidates, and three allocation variants per candidate. Variants 0 and 1 are
calibration particles and variant 2 is held out for validation, producing 36
distinct particles. Raw hidden card identities bind opaque particle
fingerprints but are not serialized.

## History-conditioned range boundary

`LoggedTrajectoryBootstrapProvider.predict_public_range` executes only the
Phase 6I `public_encoder` and `range_head`. It accepts no private features,
legal actions, selected completion, or future-reveal labels.

`LoggedTrajectoryNativePublicRangeProvider` first reconstructs the same
public-feature schema used by Phase 6I. Its causal revealed-card range supplies
the range-entropy features; the neural head then predicts a distribution over
the six declared candidates. The selected native completion is attached only
after prediction as `candidate_id_supervision_only` for scoring.

This is an offline model applied to native public observations. It is not
official hidden state, an official posterior, or a calibrated belief merely
because descendant observations were generated by the licensed engine.

## Checked result

Each particle contributes six player-0 public decision rows. The dataset
therefore contains 216 rows, including 72 held-out allocation-validation rows,
and 274 genuine native descendant transitions.

| Validation metric | Neural range | Causal revealed-card range | Uniform |
|---|---:|---:|---:|
| NLL | 1.810882 | 0.895880 | 1.791759 |
| Brier score | 0.852283 | 0.416667 | 0.833333 |
| Top-1 accuracy | 19.444% | 56.944% | 16.667% |
| Expected calibration error | 0.320267 | 0.027777 | 0.000000 |

The neural head loses `0.019122` NLL to uniform and `0.915001` NLL to the
causal updater, with ECE above the predeclared `0.20` ceiling. Its allocation-
generalization gate is false. The calibration slice independently shows the
same ordering: neural NLL `1.852019`, causal NLL `0.982980`, and uniform NLL
`1.791759`.

The causal updater is promising, but these rows are correlated descendants of
only two native roots under supplied candidate/allocation particles. It is not
promoted to `public_belief_calibrated`; the declared minimum is six independent
roots plus match-disjoint official validation.

## Genuine execution versus abstraction

| Component | Classification |
|---|---|
| Descendant observations and selections | Genuine licensed native-search execution |
| Public legal actions | Genuine native legality boundary |
| Hidden allocation particles and their probabilities | Supplied research abstraction |
| Candidate truth labels | Evaluation-only research labels |
| Causal revealed-card range | Deterministic public-only abstraction |
| Phase 6I neural range | Offline learned abstraction |
| Range metrics and gates | Research evaluation, not official performance |

## Fail-closed consequence

Phase 6T builds no counterfactual-value bound and enables no resolver,
exploitation overlay, official strategy controller, packager, or Kaggle
submission. It does not satisfy Phase 6Q's belief-calibration prerequisite.

The next belief step should use the causal revealed-card updater as the
baseline/teacher, add action-history likelihoods only when they improve
match-disjoint NLL, and collect at least six independent native roots plus more
official replays. In parallel, leaf-value work still needs lower-noise terminal
continuations and an allocation-heldout value model; the Phase 6S full-width
interval remains unchanged.

Phase 6U supplies ten-rollout allocation-heldout targets. It passes the target
standard-error threshold but rejects both existing learned value heads and
retains a full-width interval, isolating model bias as the remaining leaf
blocker. See `docs/PHASE6U_LOW_NOISE_NATIVE_LEAF.md`.

Phase 6V purpose-trains a public-only scalar and improves point RMSE on a fresh
allocation family, but its interval remains nearly full-width. Belief and
counterfactual calibration remain separate unresolved prerequisites. See
`docs/PHASE6V_PUBLIC_NATIVE_LEAF.md`.
